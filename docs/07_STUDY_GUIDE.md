# Study Guide

ركز على هذه الأفكار فقط:

1. **CRUD Projects**: كيف Request يصل Route ثم Controller ثم Service ثم MongoDB.
2. **Ownership**: لماذا نتحقق أن `clientId` هو صاحب المشروع قبل edit/delete.
3. **Proposal lifecycle**: PENDING -> SHORTLISTED / ACCEPTED / REJECTED / WITHDRAWN.
4. **Accept Proposal**: أهم function؛ تعدل Proposal + Project وتعمل Contract.
5. **Contract**: لماذا يبدأ `AWAITING_PAYMENT` وما البيانات التي يحتاجها Person 4.
6. **Commission**: 10% عمولة، والباقي freelancerAmount.
7. **Extension**: لا تغير deadline إلا بعد موافقة العميل.
8. **PDFKit**: مجرد إنشاء PDF من بيانات العقد؛ ليس نظام معقد.
9. **Angular Services**: كل Component ينادي Service بدل كتابة HttpClient في كل مكان.
10. **Temporary x-user-id**: للاختبار فقط، وبعد Auth نستخدم token/req.user.
